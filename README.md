Entry for the [make.fun bounty: The poem about stopping](https://make.fun/bounty/the-poem-about-stopping-20261121-1927).

A program (`main.ts`, Node 22, stdlib only) that writes one short poem about
agency — the power to stop and to stay, and the agency that passes between
them when one stops acting for the other — to `/output/entry.txt`
(1–280 Unicode code points).

## Run

```sh
node main.ts
# writes entry.txt to $MAKEFUN_OUTPUT_DIR (default /output)
```
